# SEO Audit Command

Perform a comprehensive SEO audit of the Laws Electrical website.

## Instructions

Use Firecrawl MCP to crawl the website and analyse:

### Technical SEO
1. **Meta tags** - Check all pages for:
   - Title tags (50-60 characters, includes target keyword)
   - Meta descriptions (150-160 characters, includes CTA)
   - H1 tags (one per page, matches intent)
   - Header hierarchy (H1 > H2 > H3, logical structure)

2. **Performance indicators**:
   - Image alt tags (descriptive, include keywords where natural)
   - Internal linking structure
   - Broken links
   - Missing canonical tags

3. **Schema markup** - Check for:
   - LocalBusiness schema
   - Service schema
   - FAQ schema (on service pages)
   - Review/testimonial schema

### Content Analysis
1. **Keyword targeting** - Check each page targets:
   - Primary keyword in title, H1, first paragraph
   - Secondary keywords in H2s and body
   - Local modifiers (Brisbane, Wacol, etc.)

2. **Content gaps** - Identify missing:
   - Service pages
   - Suburb landing pages
   - FAQ content
   - Blog/resource content

### Local SEO
1. **NAP consistency** - Name, Address, Phone across all pages
2. **Service area coverage** - Suburb pages needed
3. **Google Business Profile alignment**

## Output Format

Provide a prioritised report with:
1. **Critical issues** (blocking rankings)
2. **High priority** (significant impact)
3. **Medium priority** (incremental improvements)
4. **Opportunities** (content gaps, new pages)

For each issue, provide:
- Page URL
- Current state
- Recommended fix
- WordPress MCP command to implement (if applicable)
